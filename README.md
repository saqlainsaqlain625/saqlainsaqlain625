### 🏠 Intario AI — AI-Powered Interior Designing App

**Tech Stack:** `Flutter` `Dart` `Firebase` `Decor8 AI API` `Unity` `AR`

A cross-platform mobile application prototype designed to help users visualize interior transformations using artificial intelligence and augmented reality.

**Key Highlights:**

- Integration experiments with Unity for AR-based interior visualization

### 📈 CIBMTR Survival Prediction — Kaggle ML Project

**Tech Stack:** `Python` `XGBoost` `LightGBM` `Pandas` `Scikit-Learn`

A competitive machine learning project predicting survival outcomes for allogeneic hematopoietic cell transplantation.

**Key Highlights:**
- Explored and preprocessed clinical dataset for tabular modeling
- Experimented with XGBoost and LightGBM, feature engineering, cross-validation, and model evaluation
- Achieved a **C-Index score of 0.6856**

### 🌐 Python Quotes Web Scraping & Analysis

**Tech Stack:** `Python` `Requests` `BeautifulSoup4` `Pandas` `Matplotlib`

A complete web scraping and exploratory data analysis project extracting quotes and author information across multiple pages from [Quotes to Scrape](https://quotes.toscrape.com/).

**Key Highlights:**
- Automated multi-page HTTP requests and HTML parsing using Requests and BeautifulSoup
- Extracted and validated a dataset of 100 quotes with zero missing or duplicate records
- Exported structured data to CSV for downstream analysis
- Analyzed author frequency and visualized the top 10 authors with Matplotlib charts
- Implemented reusable quote keyword and author search functions

**🔗 [Explore Python Quotes Web Scraping on GitHub](https://github.com/saqlainsaqlain625/python-quotes-web-scraping)**
